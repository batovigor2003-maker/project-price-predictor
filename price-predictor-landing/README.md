# Лендинг Чекбилет

Статичный одностраничный лендинг (Astro + Tailwind CSS 4). Макет и тексты — в папке `design/`.

## Запуск

```bash
pnpm install
pnpm dev        # http://localhost:4321
pnpm build      # готовый сайт в папке dist/
```

## Настройка

Адрес приложения, куда ведут все кнопки «Проверить билет», задаётся в `.env`:

```
PUBLIC_APP_URL=https://адрес-приложения
```

По умолчанию кнопки ведут на `https://app.checkbilet.ru`. Демо-данные (маршрут, цены, прогнозы) — в `src/data/forecast.ts`.

## Выкатка

Отправьте изменения лендинга в `main`. GitHub Actions соберёт HTML, CSS, скрипты и изображения, передаст их на сервер и переключит Nginx на новую сборку. Запуск считается успешным, когда публичная главная страница отвечает `200` и совпадает со сборкой этого коммита.

Проверить результат можно во вкладке [Actions](https://github.com/batovigor2003-maker/project-price-predictor/actions/workflows/deploy-landing.yml). Откройте [лендинг](https://checkbilet.ru) и нажмите «Проверить билет», чтобы перейти в приложение.
