# Handoff: лендинг Чекбилет

## Overview
Одностраничный статичный лендинг сервиса Чекбилет (прогноз изменения цены авиабилета). **Одно целевое действие** — переход в приложение по кнопке «Проверить билет» (3 кнопки на десктопе, 2 на мобильном, все ведут на один URL приложения — `APP_URL`, задать в конфиге).

Стек: **Astro + Tailwind CSS v4**, статичный билд (`output: 'static'`). Интерактив — только авто-анимация прогноза (vanilla JS, `<script>` в Astro-компоненте, без фреймворков-островов).

## About the Design Files
`design-reference.dc.html` — **дизайн-референс в HTML**, а не продакшн-код. Открывается в браузере рядом с `support.js`. В файле несколько раундов вариантов; финальные:
- **3a** — мобильная версия (390 px), секция `#t3`
- **4a** — десктопная версия (1440 px), секция `#t4`

Остальные (1a–1d, 2a–2d) — отброшенные исследования, игнорировать. Задача — воссоздать 3a/4a на Astro + Tailwind 4 одной адаптивной страницей.

## Fidelity
**High-fidelity.** Цвета, шрифты, размеры, отступы и анимация — финальные. Верстать pixel-perfect для 390 и 1440; промежуточные ширины — плавно (см. Responsive).

## Тексты

## Interactions & Behavior
- **Все кнопки** — `<a href={APP_URL}>`, hover: жёлтые → `#ffe199`, тёмная → `#0b2cb1`. Добавить `transition: background-color .2s`, видимый `focus-visible` ring (например, 3px `#03195b` offset 2).
- **Авто-цикл прогноза**: состояние `i ∈ {0: снизится, 1: вырастет, 2: без изменений}`, `setInterval` 2800 ms, по кругу. Одно состояние синхронно управляет: прогнозом в талоне hero, процентом над графиком, высотами/цветом столбиков, подсветкой строки списка.
- Высоты столбиков (% от высоты графика):
  - снизится: `50 58 62 70 66 60 52 46 40 36`
  - вырастет: `40 44 50 48 56 62 70 78 86 96`
  - без изменений: `56 60 58 62 57 60 59 61 58 60`
- Переходы: `height .6s`, `background .4s`, `color .4s` (ease по умолчанию).
- `prefers-reduced-motion: reduce` → не запускать цикл, показать «снизится».
- Цикл можно ставить на паузу, когда блок вне экрана (IntersectionObserver) — опционально.
- Реализация: разметка с `data-*` атрибутами в Astro, один `<script>` (бандлится Astro) переключает `data-state` на корне + обновляет текст/инлайн-высоты. Без React.

## Tailwind 4
Токены задать в `@theme` в `src/styles/global.css`, например:
```css
@import "tailwindcss";
@theme {
  --font-sans: "Rubik", system-ui, sans-serif;
  --color-navy-900: #03195b; --color-blue-800: #0b2cb1; --color-blue-600: #1951fc;
  --color-blue-500: #3781fc; --color-sky-200: #cbe9fd; --color-sky-300: #9fcafd;
  --color-bg: #f4faff; --color-line: #dbe6f7; --color-muted: #5d6c96;
  --color-accent: #FFD166; --color-accent-hover: #ffe199;
  --color-down: #2fd189; --color-up: #ff5a6e; --color-flat: #FFD166;
}
```
Рекомендуемая структура: `src/pages/index.astro`, `src/components/{Hero,Ticket,Problem,Solution,ForecastCard,Benefit,FinalCta,Logo}.astro`, `src/data/forecast.ts` (тексты прогнозов, высоты столбиков, демо-данные), `src/scripts/forecast-cycle.ts`.
