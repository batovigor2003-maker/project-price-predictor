# Чекбилет

Демонстрационное приложение для выбора момента покупки авиабилета по России. В базе примеров — 100 синтетических билетов с предполагаемым изменением цены за 7 дней и советом «купить сейчас» или «подождать». Это тестовые цены и сценарии, а не прогноз, проверенный на реальном рынке.

## Быстрый запуск

Понадобятся Node.js, pnpm и, для хранения данных в PostgreSQL, Docker Desktop.

```bash
pnpm install
pnpm dev
```

Откройте http://127.0.0.1:3000. Если Docker недоступен, приложение показывает те же 100 подготовленных сценариев из кода. В этом режиме на экране написано «Демо-режим».

## Запуск с PostgreSQL

В корне проекта уже есть локальный `.env`. Если его нет, скопируйте `.env.example` в `.env`. Если PostgreSQL на порту 5432 ещё не запущен, поднимите его:

```bash
docker compose up -d
```

Если контейнер PostgreSQL этого проекта уже работает, не запускайте второй контейнер на том же порту. В обоих случаях затем выполните:

```bash
pnpm db:migrate
pnpm db:seed
pnpm dev
```

Скрипт заполнения добавляет 100 билетов только в пустую таблицу и не удаляет существующие записи. Когда база доступна, каталог показывает пометку «Данные из PostgreSQL».

## Как проверить руками

1. Откройте главную страницу и убедитесь, что каталог показывает 100 билетов.
2. Нажмите на любой билет. Вы увидите цену сейчас, тестовую цену через 7 дней, направление изменения и совет.
3. Попробуйте билеты с разными метками: «Вырастет», «Снизится», «Почти без изменений».
4. Введите в форме сочетание параметров, которого нет среди примеров. Приложение сообщит, что для него нет тестового прогноза.
5. При включённой базе проверьте над каталогом пометку «Данные из PostgreSQL».

## Принятые правила демо

Горизонт — 7 дней. Изменение от −5% до +5% включительно считается почти неизменной ценой. Обратная дата необязательна. Уверенность прогноза не показывается, поскольку качество на фактических ценах ещё не измерено. Источник реальных цен и метод прогноза должны быть согласованы до их реализации.
