# Чекбилет

Демонстрационное приложение для выбора момента покупки авиабилета по России. В базе примеров — 100 синтетических билетов с предполагаемым изменением цены за 7 дней и советом «купить сейчас» или «подождать». Это тестовые цены и сценарии, а не прогноз, проверенный на реальном рынке.

## Быстрый запуск

Понадобятся Node.js, pnpm и, для хранения данных в PostgreSQL, Docker Desktop.

```bash
pnpm install
pnpm dev
```

Откройте http://127.0.0.1:3000. Чтобы посмотреть приложение на телефоне, подключите его к той же сети Wi-Fi и откройте `http://<IP-адрес Mac>:3000`. Команда `pnpm dev` принимает подключения из локальной сети. Если Docker недоступен, приложение использует 100 подготовленных сценариев из кода.

## Запуск с PostgreSQL

В корне проекта уже есть локальный `.env`. Если его нет, скопируйте `.env.example` в `.env`. Если PostgreSQL на порту 5432 ещё не запущен, поднимите его:

```bash
docker compose up -d
```

Если контейнер PostgreSQL этого проекта уже работает, не запускайте второй контейнер на том же порту. В обоих случаях затем выполните:

```bash
pnpm db:migrate
pnpm db:seed
pnpm dev
```

Скрипт заполнения добавляет 100 билетов только в пустую таблицу и не удаляет существующие записи.

## Как проверить руками

1. Откройте главную страницу и найдите блок «Что ищут другие 👀» с примерами маршрутов.
2. Нажмите на любой маршрут. Вы увидите цену сейчас, тестовую цену через 7 дней, направление изменения и совет.
3. Проверьте несколько маршрутов с разными результатами: «Вырастет», «Снизится», «Почти без изменений».
4. Введите в форме сочетание параметров, которого нет среди примеров. Приложение сообщит, что для него нет тестового прогноза.

## Принятые правила демо

Горизонт — 7 дней. Изменение от −5% до +5% включительно считается почти неизменной ценой. Обратная дата необязательна. Уверенность прогноза не показывается, поскольку качество на фактических ценах ещё не измерено. Источник реальных цен и метод прогноза должны быть согласованы до их реализации.

## Выкатка на сервер

Когда изменения попадают в `main`, GitHub Actions проверяет проект, собирает Docker-образ и публикует его в GHCR с полным SHA коммита. Сервер скачивает этот образ, применяет миграции PostgreSQL и запускает приложение. Выкатка проходит успешно, когда [проверка приложения](https://app.checkbilet.ru/health) отвечает по HTTPS со статусом 200 и SHA новой версии. При ошибке откройте журнал запуска во вкладке [Actions](https://github.com/batovigor2003-maker/project-price-predictor/actions).

База PostgreSQL хранится в отдельном томе Docker. На сервере пароль задаётся в файле `~/checkbilet-deploy/.env` строкой `POSTGRES_PASSWORD=...`. Для новой базы значение можно сгенерировать командой `openssl rand -hex 32`. Тестовые данные загружаются отдельно один раз после первой выкатки.

Для ручной проверки откройте [Чекбилет](https://app.checkbilet.ru), выберите один из предложенных маршрутов и проверьте, что отображаются цена и совет по покупке.
